# Kubernetes Cluster Component Security (ATS042)

Kubernetes and Cloud Native Associate (KCSA) — Kubernetes Cluster Component Security, 22% of the published curriculum. This course is part of ATP009.

Concept lessons explain each official objective through concrete examples, diagrams and scenario reasoning. Every section begins with an introduction, and every module ends with a summary. Reusable YAML question banks include the correct answer, option feedback and learning-objective mapping.

## Authoring Status

Each section has one module with a playground, a graded lab, a capstone lab and a knowledge check, and the course ends with a final domain quiz. Labs and playgrounds are UNTESTED: built with static checks only (`astrona validate`, `bash -n`, YAML parsing). Technical pages stay draft until the maintainer approves publication. The earlier YAML question banks stay in `assessments/`.
