# Etcd And Stored Cluster Data

This module develops the reasoning needed to explain why direct etcd access is a powerful security boundary.

## Learning Goals

- Explain why direct etcd access is a powerful security boundary.
- Distinguish transport encryption, storage encryption and authorization.
- Relate quorum, backups and access control to recovery.
- Identify sensitive information in datastore snapshots.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
