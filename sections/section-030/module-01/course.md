# Scheduler Integrity And Availability

This module develops the reasoning needed to explain what the scheduler decides and what it cannot execute.

## Learning Goals

- Explain what the scheduler decides and what it cannot execute.
- Relate node labels and placement rules to security assumptions.
- Identify the impact of scheduler identity or configuration compromise.
- Distinguish placement controls from complete tenant isolation.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
