# Kubelet

This section teaches kubelet and node access. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Kubelet And Node Access. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. Reusable YAML checkpoints review related objectives after selected section summaries. The course assessment index records their placement and coverage.

## Learning Outcomes

- Explain the kubelet's authority over assigned Pods.
- Distinguish API permissions from direct node-agent access.
- Identify sensitive data available through node and workload operations.
- Relate node credentials and endpoint protection to cluster trust.
