# Kubelet And Node Access

This module develops the reasoning needed to explain the kubelet's authority over assigned Pods.

## Learning Goals

- Explain the kubelet's authority over assigned Pods.
- Distinguish API permissions from direct node-agent access.
- Identify sensitive data available through node and workload operations.
- Relate node credentials and endpoint protection to cluster trust.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
