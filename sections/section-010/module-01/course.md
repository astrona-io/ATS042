# API Server Security Boundaries

This module develops the reasoning needed to explain the API server's identity, permission and admission checks.

## Learning Goals

- Explain the API server's identity, permission and admission checks.
- Relate API transport protection to authenticated peer identity.
- Identify risks from excessive API exposure and powerful credentials.
- Distinguish API audit evidence from application request logs.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
