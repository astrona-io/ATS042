# Storage Access And Data Security

This module develops the reasoning needed to distinguish API storage resources from backend data permissions.

## Learning Goals

- Distinguish API storage resources from backend data permissions.
- Explain confidentiality risks in volume mounts and snapshots.
- Relate encryption, reclaim policy and recovery to data protection.
- Identify node and driver trust in mounted storage.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
