# KubeProxy And Service Forwarding

This module develops the reasoning needed to explain kube-proxy's Service forwarding responsibility.

## Learning Goals

- Explain kube-proxy's Service forwarding responsibility.
- Distinguish forwarding from authentication and encryption.
- Identify risks from compromised forwarding configuration.
- Relate alternative implementations to the same security contract.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
