# Controller Manager

This section teaches controller manager authority. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Controller Manager Authority. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. Reusable YAML checkpoints review related objectives after selected section summaries. The course assessment index records their placement and coverage.

## Learning Outcomes

- Explain controller reconciliation and API permissions.
- Identify consequences of a compromised controller identity.
- Relate controller availability to workload recovery.
- Distinguish Kubernetes controller behavior from application data repair.
