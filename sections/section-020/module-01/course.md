# Controller Manager Authority

This module develops the reasoning needed to explain controller reconciliation and API permissions.

## Learning Goals

- Explain controller reconciliation and API permissions.
- Identify consequences of a compromised controller identity.
- Relate controller availability to workload recovery.
- Distinguish Kubernetes controller behavior from application data repair.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
