# Container Network Trust

This module develops the reasoning needed to identify the network implementation's authority and dependencies.

## Learning Goals

- Identify the network implementation's authority and dependencies.
- Distinguish Service forwarding from connection policy enforcement.
- Relate node access, plaintext traffic and trusted peers.
- Explain how network segmentation limits compromise paths.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
