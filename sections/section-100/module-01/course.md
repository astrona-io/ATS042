# Client Credentials And Configuration

This module develops the reasoning needed to explain kubeconfig credential and context risks.

## Learning Goals

- Explain kubeconfig credential and context risks.
- Relate transport verification to the intended cluster identity.
- Identify sensitive data in local files and automation logs.
- Compare routine client authority with administrative authority.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
